Install it

  1. Download the APK on your phone.
  2. Open it. If Android asks, allow installs from your browser or file manager for this one install.
  3. Open CodeForge and pick a folder, or create a project. Allow "All files access" only if you want to open folders anywhere on the device.
  4. Optional: set up the Linux environment from the Terminal menu to get node, npm, python and git.

Build it yourself

You need JDK 17 and the Android SDK (platform 34, NDK 26). The repository's CI does exactly this on every push.

# app/build/outputs/apk/debug/
$ ./gradlew assembleDebug

Or download the source ZIP and read it in the code browser.

What's new in

  • Crash recorder with shareable reports, and previews that run in a separate process
  • Top and bottom sheets that can hold the terminal, preview, AI, Git and more
  • One text size setting for the whole app, plus a much faster start
  • AI agent upgrades and the cf terminal command
  • Terminal text measured with the right font, so long lines no longer wrap early

Debug builds are signed with a debug key. A release build signed with your own key is what you should publish to Google Play.
